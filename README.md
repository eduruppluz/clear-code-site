# Clear Code ERL

Site institucional da Clear Code ERL, empresa de tecnologia e soluções digitais.

🔗 **Site no ar:** [eduruppluz.github.io/clear-code-site](https://eduruppluz.github.io/clear-code-site/)

![Preview do site](preview.png)

## Sobre o projeto

Site para apresentar a Clear Code e seus serviços: sites, landing pages, geração de leads, tráfego pago e criativos. A proposta visual é dark, premium e minimalista, com a cor do site mudando conforme a seção.

## Destaques

- Cor do site muda a cada seção durante o scroll
- Lâmpada da logo em SVG que reage à seção ativa
- Serviços em bento grid
- Processo de trabalho com animação sticky no desktop e timeline no celular
- Seção de portfólio
- Animações com Framer Motion
- Layout responsivo para celular

## Tecnologias

React • TypeScript • Vite • Tailwind CSS • Framer Motion

## Como rodar

```bash
npm install
npm run dev
```
